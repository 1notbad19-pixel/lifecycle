#  Анализатор артериального давления

> Утилита для информирования пользователя о нормальном артериальном давлении

---

##  Описание проекта

Приложение рассчитывает **идеальное артериальное давление** на основе возраста и веса пользователя, а также оценивает текущее давление как **повышенное**, **пониженное** или **нормальное**.

Проект разработан в рамках дисциплины **«Жизненный цикл разработки программного обеспечения»**.
